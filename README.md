# GameDevKit [![License](https://flat.badgen.net/github/license/GoWelkinDev/GameDevKit)](https://github.com/GoWelkinDev/GameDevKit/blob/master/LICENSE) [![GitHub release](https://flat.badgen.net/github/release/GoWelkinDev/GameDevKit)](https://github.com/GoWelkinDev/GameDevKit/releases/) [![.NET Unit Test](https://github.com/GoWelkinDev/GameDevKit/actions/workflows/dotnet-test.yml/badge.svg)](https://github.com/GoWelkinDev/GameDevKit/actions/workflows/dotnet-test.yml)

Foundational libraries for .NET game development. **NativeAOT-compatible**, cross-platform, reusable across projects.

## Packages

| Package | Description |
| --- | --- |
| `GameDevKit.Core` | Primitive types and utilities |
| `GameDevKit.Logging.Abstractions` | Logging abstraction and facade |
| `GameDevKit.Networking.Abstractions` | Protocol DTOs |
| `GameDevKit.Networking.Transport` | LiteNetLib transport layer |
| `GameDevKit.Platforms.Abstractions` | Platform abstraction |
| `GameDevKit.Platforms.Steam` | Steamworks.NET implementation |
| `GameDevKit.Serialization` | Config contract, JSON serializer |
| `GameDevKit.Test` | Unit test project |
